01Việc mỗi người làm ngay

Tick vào từng mục khi làm xong. Trạng thái chỉ lưu trên trình duyệt của bạn.

Lưu ý

  • Không dùng XAMPP bản cũ. OSPOS yêu cầu PHP từ 8.2 trở lên kèm extension intl và gd. XAMPP phổ biến hiện nay đi kèm PHP 8.0 hoặc 8.2 bản cũ nên không chạy được.
  • Chỉ tải từ GitHub chính thức. Một số trang bán lại OSPOS với giá khoảng $39. Đó là tiền dịch vụ hỗ trợ của bên thứ ba, nhóm không cần mua.

02Kiến thức cần ôn trước

Backend

  • PHP cơ bản và lập trình hướng đối tượng
  • CodeIgniter 4: mô hình MVC, Routes, Migrations
  • MySQL: truy vấn, khóa ngoại, JOIN

Frontend

  • HTML, CSS, Bootstrap
  • jQuery và gọi AJAX
  • Đọc hiểu View của CodeIgniter

Làm việc nhóm

  • Git: branch, commit, pull, merge
  • GitHub: fork, Pull Request, Issues
  • Xử lý xung đột khi merge

Lý thuyết nguồn mở

  • Các loại giấy phép: MIT, GPL, Apache
  • Fork và đóng góp cho dự án nguồn mở
  • Mô hình kinh doanh của phần mềm nguồn mở

04Phân công gợi ý

Điều chỉnh theo số người trong nhóm. Một người có thể nhận hai vai trò.

Vai tròCông việc
Trưởng nhómFork repo, quản lý branch và Pull Request, chia việc, tổng hợp báo cáo
BackendController và Model cho bàn, ghi chú món, size, báo cáo doanh thu
FrontendGiao diện sơ đồ bàn, màn hình gọi món, mẫu hóa đơn
Phân tích, CSDLKhảo sát nghiệp vụ quán cà phê, vẽ use case, ERD, thiết kế bảng mới
Kiểm thử, tài liệuViết test case, README hướng dẫn cài đặt, slide thuyết trình

05Lộ trình

  1. GĐ1

    Tìm hiểu

    Cài đặt công cụ, chạy được OSPOS trên máy, dùng thử và liệt kê chức năng.

  2. GĐ2

    Phân tích, thiết kế

    Khảo sát quán cà phê, chốt danh sách chức năng làm thêm, vẽ use case, ERD, phác thảo giao diện.

  3. GĐ3

    Phát triển

    Mỗi người làm trên branch riêng, gửi Pull Request để trưởng nhóm duyệt.

  4. GĐ4

    Kiểm thử, đóng gói

    Chạy test case, sửa lỗi, viết README và hướng dẫn cài đặt.

  5. GĐ5

    Báo cáo, thuyết trình

    Hoàn thiện báo cáo, slide, chuẩn bị dữ liệu demo.

06Khung báo cáo gợi ý

  1. Tổng quan về phần mềm nguồn mở khái niệm, giấy phép MIT, lý do chọn nguồn mở
  2. Giới thiệu OpenSourcePOS và công nghệ PHP, CodeIgniter 4, MySQL, kiến trúc MVC
  3. Phân tích và thiết kế nghiệp vụ quán cà phê, use case, ERD, giao diện
  4. Cài đặt và phát triển các chức năng nhóm bổ sung, so sánh trước và sau
  5. Kiểm thử, kết luận, hướng phát triển
